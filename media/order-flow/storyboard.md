# 一单面粉 · 分镜表

以当前工作树的交易 API 为依据，用同一张示例订单演示从报价到签收。蓝青表示等待或预留，琥珀表示已确认，红色表示分支失败或关单。取 C 夜曲，以票据、面粉袋、预留托盘及运单回场。

## 开场取舍

- 采用订单号先到、货还没动的画面。它直接引出受理与库存回执的时间差。
- 备选是同一次提交点两回，留给后面的幂等一镜。
- 备选是两袋面粉只剩一袋，留给缺货分支对照。

9–15 秒留片名。约每 20–30 秒安排一次无字幕停顿，转场和最后的来源卡也留空。商品、批次与金额为示例。各场景从一次位移或状态变化开始，再留时间阅读。
