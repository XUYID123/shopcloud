# 商品分类列表查询

日期：2026-10-30。商品分类列表已实现于 shop-product，沿用原 MyBatis、统一 Result 和公共内部 JWT 过滤器；没有新增依赖、数据库迁移或 Redis 缓存。

## 接口

```http
GET http://localhost:8888/api/v1/categories
```

前端无需 Token、请求体或身份头。仅返回 enabled=1 的平级分类，按 sort 升序，再按 id 升序，不分页。HTTP 200，统一响应的 data 示例：

```json
[
  {"categoryId":"1","name":"高筋面粉","sort":10},
  {"categoryId":"2","name":"中筋面粉","sort":20}
]
```

无分类时 data=[]，不返回 null。每项只含 categoryId/name/sort，不返回 enabled、时间和数据库实体。categoryId 为字符串。响应头 X-Trace-Id/X-Request-Id 和正文 traceId 使用同一关联编号。

暂时性数据库故障返回 503 DEPENDENCY_UNAVAILABLE；SQL/程序错误沿用全局 500，不将故障伪装成空结果。限流/防刷仍沿用网关 429/503 约定。

## 代码执行过程

1. 网关先完成入口清洗、Sentinel 与 Redis 防刷；GET /api/v1/categories 已在匿名白名单。
2. 网关签发 aud=shop-product、kind=anonymous、绑定 GET 和最终路径的短期内部 JWT。
3. 商品服务公共 InternalAuthenticationFilter 验证签名、有效期、受众、请求绑定及匿名路径范围；直连服务缺少内部凭据仍返回 401。
4. [CategoryController.list](../shop-product/src/main/java/org/spring/shopproduct/controller/CategoryController.java) 接收公开 GET，返回 Result<List<CategoryListItemVO>>。原创建接口 POST /api/v1/admin/categories 保持不变。
5. [CategoryService.listEnabled](../shop-product/src/main/java/org/spring/shopproduct/service/CategoryService.java) 读取分类，映射为只含三个字段的 [CategoryListItemVO](../shop-product/src/main/java/org/spring/shopproduct/vo/CategoryListItemVO.java)。
6. [CategoryMapper](../shop-product/src/main/java/org/spring/shopproduct/mapper/CategoryMapper.java) 调用 [XML 查询](../shop-product/src/main/resources/mapper/CategoryMapper.xml)：

```sql
SELECT id, name, sort
FROM category
WHERE enabled = 1
ORDER BY sort ASC, id ASC;
```

表中已有 (enabled, sort, id) 索引。只读本服务商品库，不经过 Feign 查询其他服务。公开列表不能查询禁用分类，也未扩展后台列表或分类详情接口。
