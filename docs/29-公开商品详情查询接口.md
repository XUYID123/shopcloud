# 公开商品详情查询

实现日期：2026-11-02。

```http
GET http://localhost:8888/api/v1/products/10001
```

前端无需 Token、请求体或身份头。网关继续执行 Sentinel 限流和 6380 IP 防刷；已有 GET 白名单放行后，由网关签发绑定该 GET 路径的内部匿名 JWT。商品服务公共过滤器验证签名、目标服务、有效期及请求绑定，再进入控制器。直接访问商品服务端口且没有有效内部凭据，仍返回 401。

## 行为约定

- 路径 productId 必须是正整数十进制字符串，不超过 Long.MAX_VALUE，不接受前导零。非法值返回 400 / VALIDATION_ERROR。
- 商品必须 ON_SALE，且所属分类启用。不存在、未上架或分类禁用统一返回 404 / PRODUCT_NOT_FOUND，不返回隐藏商品资料。
- 成功返回 200 / Result<ProductDetail>；基础信息字段沿用原契约，skus 只包含启用规格，按 SKU 主键升序排列。
- skus 没有记录时返回 []。库存尚未接入，每项 estimatedAvailable 明确为 null，不伪造零库存。
- 查询不修改商品状态或版本。管理员访问公开路径也不能读取下架商品；管理端详情接口尚未实现。
- 数据库暂时性故障返回 503 / DEPENDENCY_UNAVAILABLE，不用 404 或空规格掩盖失败；SQL 程序错误仍由公共异常处理器返回 500。成功和拒绝响应均沿用 Trace ID。

## 代码执行

1. [PublicProductController](../shop-product/src/main/java/org/spring/shopproduct/controller/PublicProductController.java) 接收 GET /api/v1/products/{productId}，只做 HTTP 适配和统一响应包装。
2. [ProductQueryService](../shop-product/src/main/java/org/spring/shopproduct/service/ProductQueryService.java) 验证路径 ID，开启 readOnly=true、REPEATABLE_READ 的本地事务。
3. [ProductMapper.xml](../shop-product/src/main/resources/mapper/ProductMapper.xml) 的 selectVisibleById 通过 JOIN category，并在 SQL 中过滤 ON_SALE 与 c.enabled=1；按主键绑定参数查询。
4. [SkuMapper.xml](../shop-product/src/main/resources/mapper/SkuMapper.xml) 的 selectEnabledByProduct 查询 product_id 对应的 enabled=1 规格；使用已有复合索引，不进行持锁查询。
5. 显式映射为已有 ProductCreatedVO / SkuCreatedVO 对应的 ProductDetail / Sku 契约。保留历史 Java 类型名称，避免扩大改动；公开列表与管理写入响应的规格过滤规则不同。

两次普通 SELECT 使用同一可重复读快照，不加 FOR SHARE 或 FOR UPDATE。查询反映快照建立时的可见状态；若同时发生下架，本次已开始的查询可能返回原快照，之后新请求读取新状态。下单时仍必须重新校验销售资格与库存，不能以此前详情页为交易依据。

本次不引入缓存、远程调用或新表。不修改 POM、application 配置文件及已有 JWT/RBAC/限流实现。公开查询已有白名单，无需发布新的 RBAC 规则。
