# 客户商城与 CRM 商品导入

## 本轮导入方案

用户本轮授权读取已登录目录、保存到项目、写入本机商品库并展示。CRM 当前选择五得利集团周口面粉有限公司。核对未筛选清单发布的 238 条和各页唯一商品 ID，再逐条提取允许字段。CRM 未公开独立 SPU 编码，演示用 SPU 按来源分类、品牌和去除明确包装后缀的商品名保守归组。保留完整品名、原 ID、SKU 货号、原规格和人民币报价，源未提供报价单位。缺失价格保留为空，吨包、散装和非面粉商品保留原始业务含义。

- MySQL REQUIRED。使用 V5 增量迁移管理独立的 CRM 目录快照。全量 SPU/SKU 按一个 JSON 文档事务写入，SHA-256 唯一约束保障重试幂等，导入后回读逐字段对比。商品库现有四个迁移校验通过，现有销售表为空。
- 权限与校验 REQUIRED。导入经本机开发数据库权限执行。页面只经本机前端和网关访问，商品预览路由默认关闭并校验仅服务端可见的独立令牌。只发布预览所需字段，DOM 使用纯文本和限定商品域名的 HTTPS 图片。
- 异常、日志、性能与验证 REQUIRED。复用统一错误与 Trace。列表按一次小型快照读取，浏览器按关键词、分类和分页浏览。验证完整入库、重复导入、匿名访问拒绝、网关读取与页面实测。
- Redis 与 RocketMQ NOT_REQUIRED。快照读写独立于销售商品缓存，导入为本机同步事务。正式销售目录所需售价、筋度、配料、储存和保质期的缺口须核对后才能上架。

## 分类展示

目录默认按面粉、挂面和副产品分区，每个分区显示 SPU/SKU 数量及最多四个商品。顶部品类按钮和分区内的「查看全部」可打开单类分页，搜索结果沿用同一分组逻辑。分类使用快照已有品类字段，由浏览器展示。本机页面已验证三个分区的实测数量、挂面分页、货号搜索归组和 SKU 展开，`npm.cmd --prefix shop-web run check` 的 5 项检查通过。

## 后端分页方案

- MySQL REQUIRED。分页接口接收品类、关键词、页码和页大小，通过主键定位最新快照，用 `JSON_TABLE` 提取 SPU 与 SKU、计算匹配数，再按快照中的 SPU 顺序执行 `LIMIT/OFFSET`。分类总览按品类返回计数和至多四个预览 SPU。现有 JSON 快照可直接查询，扫描成本随单份快照大小变化。
- 参数校验、权限、异常与日志 REQUIRED。沿用本机预览令牌、统一业务响应与 Trace，页码和页大小复用商品校验，参数绑定并按字面匹配搜索。列表和计数在同一次只读事务中读取同一快照。
- Redis 与 RocketMQ NOT_REQUIRED。新入口为只读查询，无写入幂等或异步处理。导入可以并发追加快照，当前请求继续读开始时选定的版本。
- 验证 REQUIRED。检查默认、分类、关键词、越界与非法参数、裸请求拒绝和真实浏览器翻页；回归现有项目检查。

### 接口与验收

- `GET /api/v1/products/crm-catalog` 支持 `category`、`keyword`、`page`、`size`。页码从 1 开始，默认 12 条、最多 50 条，页大小按 SPU 计。响应返回当前页 `items` 与匹配数 `total`、`skuCount`，越界页返回空列表。匹配 SKU 的名称或货号时返回其所属 SPU 的全部规格。
- `GET /api/v1/products/crm-catalog/overview` 支持 `keyword`，返回品类导航和每个命中品类最多 4 个商品。两个接口都由商品库查询，按快照原始位置稳定排序。商品服务通过主键倒序取最新快照，再按主键等值展开这一份 JSON。分类计数和分页在同一只读事务内完成。
- 隔离 MySQL 和 Redis 上 Maven `test` 通过，公共模块 46 项、商品模块 55 项，其中包含 3 项 CRM HTTP/MySQL 集成测试。前端 5 项检查通过。
- 网关实测逐页读取面粉 6 页、挂面 4 页、副产品 2 页，与快照中的 125 个 SPU、238 个 SKU 逐项一致。另确认非法页大小、越界页、分类总览、搜索和预览令牌校验。浏览器实测挂面第 1 页、第 2 页各 12 个 SPU 且编号无重复，货号搜索与 SKU 展开通过。

## CRM 分类维度

- MySQL REQUIRED。项目快照保存 CRM 分类选项及每个 SKU 的实际属性，按已有 SHA-256 幂等流程追加上传。应用在同一 SKU 上合并所选条件，再按 SPU 归组、计数、分页。读取既有快照使用相同查询，字段缺失仍可在「全部」下浏览。复用现有只读事务、预览权限、Trace 和异常响应。
- 参数校验与测试 REQUIRED。九个查询字段使用允许列表与 SQL 绑定。同一维度单选，不同维度交集。选项保留 CRM 顺序，零结果正常显示。Redis 与 RocketMQ NOT_REQUIRED，此次增加同步查询和本机快照属性。

品类、定额分类、品牌、类别、包装形式、渠道、规格、星级和用途与 CRM 商品列表选项对应。定额分类根据 CRM 的商品 ID 对齐全部 238 条详情，其中 169 个 SKU 有赋值。新快照 ID 为 3，包含相同的 125 个 SPU、238 个 SKU，数据库回读与项目文件逐字段一致。预览接口返回筛选选项与相应结果，所选条件随分页请求发送，SKU 展开只显示符合所选维度的规格。

隔离环境通过 Maven 102 项后端测试，含 4 项 CRM 集成测试，前端 5 项检查通过。真实网关逐个核对九个维度，并验证组合查询和空结果。Chrome 中选择面粉、一类高富类、五得利和彩包，得到 26 个 SPU、47 个 SKU，翻到第 2 页仍采用四个筛选条件。
