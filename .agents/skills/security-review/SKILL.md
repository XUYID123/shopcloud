# security-review

## 工作流程

1. 读 [安全知识页](../../../docs/security/README.md)。从网关路由/匿名白名单到内部 JWT 及 Service 归属查询追踪身份，检查可信声明、角色、受众和资源 ID。
2. 核对 DTO 字段允许列表、参数绑定、敏感输出、日志/缓存/消息最小化和密钥注入。权限依赖失败沿用安全拒绝策略。
3. 对消息边界核对 TLS/认证、Topic/Group ACL、消息来源与版本校验、重放保护和追踪。
4. 用隔离测试断言匿名/过期、错误受众、超范围资源、字段注入、错误参数及权限依赖故障被拒绝。

## 输出与验收检查

输出：证据路径、影响及具体修复和负向测试。禁止使用真实凭据或生产数据。验收：每个可达写入都具备可信身份、授权和必要的归属控制。
