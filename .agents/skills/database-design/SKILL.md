# database-design

## 工作流程

1. 从 [数据库知识页](../../../docs/database/README.md) 定位模块 Flyway、Mapper 与测试。核对 schema 所有权、主键、空值、类型、唯一约束、关系和数据量。
2. 写查询形态、索引顺序、EXPLAIN 预期，明确隔离级别、事务代理、回滚、锁顺序。选择唯一约束、条件更新、乐观锁/短悲观锁并说明冲突结果。
3. 幂等键、请求指纹、业务写一起提交；需要可靠事件时读 [一致性设计](../../../docs/messaging/database-consistency.md)。记录扩展、回填、发布兼容及失败恢复。
4. 隔离环境验证空库/升级、唯一和外键约束、并发、回滚、慢查询及旧调用。

## 输出与验收检查

输出：表/索引、迁移与回滚策略、事务图、SQL 验证。禁止修改已应用迁移或用先查后写替代唯一性。验收：关键不变量、访问路径、发布顺序有执行证据。
